## 💻 About This Portfolio

A hand-built, single-page developer portfolio with a **cinematic entrance experience**.

<details>
<summary><b>✨ Features</b></summary>

- 🎬 **Cinematic intro** — animated letter sequence ending in a pixel-block disintegration reveal
- 🌑 **B&W cinematic background** — grayscale video stage across the whole site
- 🪄 **Staggered entrance animations** — navbar and hero pieces slide in sequence
- 🃏 **3D tilt cards** — skills, certificates, and project frames react to the cursor
- 📊 **Animated stats** — radial progress bars that fill on scroll
- 📱 **Fully responsive** — from phones to ultra-wide 4K displays

</details>
